# IntentOS next layer (design only)

V1 remains explicit selection → preview → Track. Future work separates commitments
(something must happen) from references (something to return to).

- Source evidence / Open Original: expose only reliable captured URLs; never fabricate links.
- Activity timeline: record user edits, completion, and reminder changes.
- Needs Attention: surface unresolved timing and waiting items without inventing obligations.
- Follow-up drafts: prepare text for user review; never send autonomously.
- READ_LATER / Reference capture: save explicitly selected page/text and its source URL,
  with an optional reminder and Open Original. Potential capture types are ACTION,
  WAITING, EVENT, REMEMBER, and READ_LATER.
- Calendar integration: create actual scheduled events only after user confirmation.
- Mobile companion: notifications, Done, Resolved, Snooze, and Open source.

None of these extensions is implemented by the V1 stabilization work.
